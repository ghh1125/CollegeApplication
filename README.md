# 高考志愿推荐系统

输入位次和偏好，自动生成冲稳保梯度志愿方案，并提供 AI 对话助手帮你分析和解读。目前已上线浙江、江苏、上海，其他省份陆续接入。

**在线体验**：[https://collegeapplication-imqdnkfg5pggujsmkofkbo.streamlit.app](https://collegeapplication-imqdnkfg5pggujsmkofkbo.streamlit.app)

> **注意事项**：本工具基于历史数据生成参考方案，不能保证录取结果。历史位次每年会有波动，部分学校/专业数据可能存在缺失或误差。**最终填报请以所在省份教育考试院官方公布的数据为准，建议同时参考学校招生章程和专业录取规则。**
>
> 本工具输出的志愿方案仅供参考，不构成填报建议。是否填报某所学校或专业，取决于考生本人的意愿、家庭情况和综合判断，请结合实际情况自行决定。

## 省份支持情况

| 省份 | 状态 | 备注 |
|------|------|------|
| 浙江 | ✅ 已上线 | 2023–2025 年历史数据，3+3（7选3），按「学校+专业」推荐（80 个），三步筛选 + 冲稳保梯度生成 |
| 江苏 | ✅ 已上线 | 2023–2025 官方院校专业组投档线，3+1+2，按「院校专业组」推荐（40 个），组内展示专业 |
| 上海 | ✅ 已上线 | 2023–2025 院校专业组投档线，3+3（6选3，单一位次池），按「院校专业组」推荐（24 个），组内展示专业 |
| 其他省份 | 🔜 开发中 | 陆续接入 |

> **三省志愿模式的区别**
> - **浙江**：3+3（7选3），志愿单位是「学校+专业」，最多 80 个。三步生成：①初步筛选（选科/学科/地域/体检/预算/单科成绩）→ ②二轮意向过滤（含预警专业标注）→ ③按位次段冲稳保采样生成 80 个志愿（高位次梯度细、低位次梯度粗）。
> - **江苏**：3+1+2（首选物理/历史 + 再选 2 门，分物理类/历史类两个位次池），志愿单位是「院校专业组」，最多 40 个。
> - **上海**：3+3（6选3，不分文理、单一位次池），志愿单位是「院校专业组」，最多 24 个，每组内设 4 个专业志愿。
>
> 江苏、上海都是「院校专业组」模式：投档检索的是专业组而非单个专业，故推荐若干院校专业组并在组内展示专业。
>
> **院校专业组为什么不做跨年加权**：江苏/上海的院校专业组**每年重新编排、组号跨年不是同一个组**（例如某校「03组」今年是理工大组、去年却是建筑组；同一个专业每年被分到不同组号）。因此不跨年加权，而是**按年份分别给出推荐**——当年推荐是实际填报方案，往年仅作同位次趋势参考、不能照填。冲稳保按各年当年官方投档位次判定。
>
> 院校专业组的组内专业明细来自公开招生计划数据；若个别专业组缺少明细，系统会保留组级投档入口并提示以官方招生计划为准。

## 能做什么

已上线省份均支持：

- **自动筛选**：根据你的选考科目，排除掉不符合要求的专业，再按学校层次、城市、专业方向进一步缩小范围
- **录取把握判断**：对比你的位次和该专业近三年历史录取位次，判断是冲、稳、保还是垫底，不靠感觉靠数据
- **三种排序模式**：专业优先（先找你想读的专业）、学校优先（先找好学校）、城市优先（先找你想去的城市），同一套数据，按你的侧重点排
- **专业相关度识别**：能区分"这就是你想读的专业"、"这个专业类里的"、"跟你想读的方向沾边"、"完全不相关"，不会把无关专业混进来
- **AI 对话助手**：不知道填什么可以跟 AI 聊，它会问你几个问题帮你分析适合读什么方向，也能解释为什么推荐某条志愿
- **实时联网查询**：询问学校或专业的评价、就业、薪资时，助手会先检索最新资料再作答，不凭空编造数据

## 快速开始

### 环境要求

- Python 3.10+
- uv（推荐）或 pip

### 安装

```bash
git clone https://github.com/ghh1125/CollegeApplication.git
cd CollegeApplication
uv sync          # 或 pip install -r requirements.txt
```

### 配置

创建 `.env` 文件：

```
DASHSCOPE_API_KEY=your_key_here
```

AI 对话功能（小明助手、报告生成）需要阿里云百炼的 API Key，志愿生成本身不需要。

### 运行

```bash
streamlit run main.py
```

## 数据来源

本项目数据均来自公开渠道，仅供学习和参考使用，不做商业用途。

**通用数据（各省共享）**

| 数据内容 | 来源 |
|---------|------|
| 学校基本信息 / 专业介绍 | [阳光高考 static-data.gaokao.cn](https://static-data.gaokao.cn) |
| 大学排名 | [软科 shanghairanking.cn](https://www.shanghairanking.cn)（手动整理） |
| 学科评估等级 | [教育部第四轮学科评估](https://www.moe.gov.cn)（2017年公开发布） |
| 城市经济数据 | [维基百科](https://zh.wikipedia.org) |

**浙江**

| 数据内容 | 来源 |
|---------|------|
| 历史录取位次 / 招生计划 | [阳光高考 chsi.com.cn](https://gaokao.chsi.com.cn)（教育部主管的官方平台） |
| 位次分段表 / 选考科目要求 | [浙江省教育考试院 zjzs.net](https://www.zjzs.net) |
| 学费 / 学制 | 浙江招录平台（公开招生计划页，按学校+专业名匹配合库） |
| 单科成绩要求 | 全国高校单科成绩要求汇总（公开整理，按校名+关键词匹配） |

**江苏**
